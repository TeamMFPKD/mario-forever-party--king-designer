This is a fan-made Mario Forever game.

It aims to connect Mario Forever enthusiasts, to make levels quickly and play them together. It is a prototype and an experimental project.

## Project Status

The current version implements the core loop: hosting a room, timed level editing, level transfer and results. The prototype validation is considered complete.

The modes that would enhance the single-player experience, the code refactoring and the controller UI improvements are all optional polish, and there is no plan to develop them further.

To restate: because of the experimental nature of this project, future updates will not follow a fixed schedule.

## Multiplayer Notes

The game depends only weakly on servers; there is no dedicated authoritative server implementation.

Hosting and joining should therefore be done on a local network. If players are in different locations, please look for tunneling tools such as NAT traversal and set them up yourself.
