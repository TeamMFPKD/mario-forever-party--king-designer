本项目是一个 Mario Forever（永远的马里奥）同人游戏。

旨在联系 Mario Forever 爱好者，快速制作关卡、并一起游玩，是原型验证、实验性项目。

## 项目概况

当前版本已实现联机建房、限时编辑、关卡传输与结算的核心玩法，原型验证已得到满足。

目前增强单机游戏体验的模式、代码重构、控制器 UI 操作优化均为甜点优化，且不计划深入开发。

仍然强调，由于本项目的实验性质，后续项目不会以固定频率进行更新。

## 联机形式特别说明

本游戏弱依赖于服务器，没有权威服务器的特别实现。

因此组织和参与游玩时，请在局域网环境下进行；若身处异地，请自行搜索内网穿透等类似工具进行组织。

## 声明

本项目与任天堂（Nintendo）的官方马力欧游戏无关。马力欧相关的素材归属任天堂所有。
